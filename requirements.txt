# ============================================================
#  Bible AI Project — Python Dependencies
#  Tested on Python 3.10 / 3.11, Windows 10/11, CPU-only
# ============================================================

# --- Core ASR ---
faster-whisper>=1.0.0       # Drop-in whisper replacement; 2-4x faster on CPU
groq>=0.11.0                # Optional: cloud Whisper fallback (transcriber.py's
                            # backend="auto"/"cloud") for machines with no usable
                            # GPU. Not needed if you'll only ever run local/CPU.
requests>=2.31.0            # Khaya API calls (transcriber.py's backend="khaya",
                            # the Twi/Ghanaian-language ASR path). Also pulled in
                            # transitively by huggingface_hub, but now a direct
                            # dependency of our own code too.
# ctranslate2 is already pulled in transitively by faster-whisper, but
# transcriber.py's backend="w2vbert" (free, fully offline Twi ASR
# fallback for when Khaya is unavailable -- 73.6% WER measured,
# meaningfully worse than Khaya, not a primary choice) uses its
# Wav2Vec2Bert model class directly, so it's a direct dependency now
# too -- measured ~2x faster than the plain-ONNX version this replaced
# (~5.9s vs. ~13s average per 7s clip on this project's own hardware).
transformers>=4.30.0        # AutoProcessor for the same backend="w2vbert" path
                            # (also already required by sentence-transformers
                            # below, but now a direct dependency too).
rapidfuzz>=3.0.0            # app/asr/backends/w2vbert.py's post-decode Twi Bible
                            # vocabulary correction -- catches ASR garbling via
                            # near-miss word matching, same conservative-threshold
                            # technique (82% similarity floor, minimum candidate
                            # length) originally validated in this codebase for
                            # reference_extractor.py's book-name fuzzy matching
                            # (since removed in a revert -- see w2vbert.py's
                            # module docstring for the current usage).
pyctcdecode>=0.5.0          # app/asr/backends/w2vbert.py's CTC beam-search decode
                            # (replaces plain greedy argmax) -- pure Python, no
                            # compiler needed. NOTE: pulls in numpy<2.0 as a
                            # dependency, which downgrades numpy if a newer one
                            # is already installed; re-run accuracy_eval after
                            # installing this to confirm nothing else regressed
                            # (verified clean on this project's own venv).

# ============================================================
#  INSTALL NOTES
# ============================================================
#
#  1. Create and activate a virtual environment:
#       python -m venv venv
#       venv\Scripts\activate          (Windows)
#
#  2. Install CPU-only PyTorch first (avoids downloading CUDA libs):
#       pip install torch --index-url https://download.pytorch.org/whl/cpu
#
#  3. Install the rest:
#       pip install -r requirements.txt
#
#  4. First run will download the Whisper model automatically
#     (stored in %USERPROFILE%\.cache\huggingface on Windows).
#     Model sizes and approximate sizes on disk:
#       tiny   ~75 MB   — very fast, lower accuracy
#       base   ~145 MB  — fast, moderate accuracy
#       small  ~460 MB  — RECOMMENDED default (good balance)
#       medium ~1.5 GB  — best accuracy, slower on CPU
#
#  REMOVED from original requirements.txt:
#    openai-whisper  — replaced by faster-whisper (same models, faster)
#    pyaudio         — replaced by sounddevice (easier to install on Windows,
#                      no PortAudio DLL headache)
